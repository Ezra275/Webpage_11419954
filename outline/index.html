demo_filter.py

# 進階技巧：使用單行串列推導式完成篩選與運算

現代網頁與伺服器端核心在於非同步處理。掌握 Promise 與 Async/Await，優雅解決非同步競態條件，確保應用程式流暢不阻塞。

  • 1

    非阻塞性資料擷取

    使用標準 fetch API 配合 async/await 語法糖進行資料獲取。

  • 2

    完整的例外捕捉

    運用 try...catch...finally 結構，建立穩健的錯誤處理機制。

fetch_service.js 
async function fetchTutorial(courseId) {
  try {
    console.log(`[API] 正在載入課程模組 #${courseId}...`);
    // 模擬網路請求
    const data = await new Promise(res => 
      setTimeout(() => res({ id: courseId, title: "VS Code Advanced Tips" }), 500)
    );
    console.log(`[SUCCESS] 載入完成: ${data.title}`);
  } catch (err) {
    console.error(`[ERROR] 載入失敗`, err);
  }
}

#include <iostream>
#include <memory>

struct Node {
    int value;
    Node(int val) : value(val) { std::cout << "節點建立: " << val << "\n"; }
    ~Node() { std::cout << "節點安全釋放: " << value << "\n"; }
};

int main() {
    auto ptr = std::make_unique<Node>(100);
    std::cout << "存取節點值: " << ptr->value << "\n";
    return 0; // 離開作用域自動呼叫解構子
}

問題：在 VS Code 中，如果要快速格式化 (Format) 整份程式碼，在 Windows 系統下的預設官方快捷鍵是什麼？

解析說明：在 Windows 系統中，Shift + Alt + F 是 VS Code 的全文件自動排版快捷鍵 (macOS 為 Shift + Option + F)；Ctrl + Shift + P 則是開啟命令面板。
